## Key Features & Implementation

### 1. Family Tree Data Structure

**CSV Format** (`familyTree.csv`):
- Columns: `id`, `parentId`, `name`, `nameBn`, `photo`, `social`
- Loaded as raw text using Vite's `?raw` import
- Parsed with PapaParse with `header: true` and `skipEmptyLines: true`

**Tree Building** (`familyData.js`):
```javascript
- Creates a flat map of nodes
- Links children to parents via parentId
- Returns single root or synthetic root if multiple roots exist
- Each node has: id, name, nameBn, photo, social, children[]
```

### 2. Tree Visualization

**TreeNode Component** ([src/components/TreeNode.jsx](src/components/TreeNode.jsx)):
- Recursive component that renders each family member
- Features:
  - **Expand/Collapse**: Toggle children visibility with chevron buttons
  - **Bilingual Display**: Shows both English name and Bengali name
  - **Social Links**: Validates URLs with regex and renders profile links
  - **Responsive Icons**: Chevron icons from Heroicons (different sizes for mobile/desktop)
  - **Smart Scroll Handling**: Uses native `scrollIntoView()` to center expanded nodes in viewport (both horizontally and vertically)
  - **Color-by-Level**: Cards automatically colored based on generation depth
- Props: `person` object, `isRoot` boolean, `depth` (generation level, 0-based), `scrollContainerRef` for container reference
- Uses `useState` for expanded state, `useRef` for DOM access, `useEffect` for scroll behavior
- Color mapping function (`getColorClass`):
  ```javascript
  Level 0: bg-red-50 border-red-300
  Level 1: bg-blue-50 border-blue-300
  Level 2: bg-green-50 border-green-300
  Level 3: bg-yellow-50 border-yellow-300
  Level 4+: bg-purple-50 border-purple-300
  ```

**Styling** ([src/styles/TreeStyles.css](src/styles/TreeStyles.css)):
- 420 lines of custom CSS
- Uses CSS Grid and Flexbox for layout
- Mobile-responsive with breakpoint at 768px
- Mobile: auto-scrolling on expand (via scrollIntoView), min-width: max-content
- Desktop: zoom: 80%, centered layout
- Connector lines between parent and children nodes

### 3. UI & Styling

- **Tailwind CSS**: Utility-first styling (bg-base-100, text-primary, etc.)
- **DaisyUI**: Pre-built components and theme system
- **Custom CSS**: TreeStyles.css handles complex tree layout and animations
- **Responsive Design**: Mobile-first approach with media queries at 768px
- **Colors & Themes**: Uses DaisyUI color scheme (primary, base-100, base-300, etc.)

### 3. **Complex Scroll Logic Refactored** (FIXED - December 29, 2025)
- **Original Issue**: 
  - 40+ lines of complex scroll-handling code with multiple timeouts
  - Separate mobile vs desktop logic causing inconsistent behavior
  - Multiple setTimeout calls (100ms, 200ms, 300ms) and requestAnimationFrame
  - Problem: When expanding nodes with 10+ children, they'd overflow off-screen to the left
- **Solution Implemented**: 
  - Replaced entire scroll handler with single native `scrollIntoView()` API
  - Automatically centers the expanded node both horizontally and vertically
  - Works identically on all platforms (mobile/desktop, all browsers)
  - Removed 90+ lines of code, keeping only 100ms delay to ensure DOM update
- **Benefits**:
  - 🎯 Single browser API (no platform detection needed)
  - ⚡ Better performance (no setTimeout loops or requestAnimationFrame)
  - 📱 Works identically on mobile and desktop
  - 🧹 Cleaner, more maintainable code

### 4. **Color-by-Level Feature Added** (NEW - December 29, 2025)
- **Feature**: Cards now change color based on generation depth
  - Level 0 (root): Red tones (bg-red-50 with red-300 border)
  - Level 1: Blue tones (bg-blue-50 with blue-300 border)
  - Level 2: Green tones (bg-green-50 with green-300 border)
  - Level 3: Yellow tones (bg-yellow-50 with yellow-300 border)
  - Level 4+: Purple tones (bg-purple-50 with purple-300 border)
- **Implementation**:
  - Added `depth` prop throughout component tree
  - `getColorClass(depth)` function maps depth to Tailwind color classes
  - Recursive increment: `depth={depth + 1}` when rendering children
- **Files Modified**:
  - [App.jsx](src/App.jsx) - Added `depth={0}` to root TreeNode
  - [TreeNode.jsx](src/components/TreeNode.jsx) - Added depth parameter and color mapping

## Data Flow

1. **CSV File** → Loaded as raw text via Vite
2. **PapaParse** → Converts CSV to array of objects
3. **familyData.js** → Builds hierarchical tree structure
4. **App.jsx** → Renders root TreeNode with tree object
5. **TreeNode.jsx** → Recursively renders each person and their children
6. **TreeStyles.css** → Applies visual tree layout and connectors
